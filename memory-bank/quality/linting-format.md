# Linting & Formatting

## Backend

**Herramientas instaladas**:
- ESLint 9.2.0
- Prettier 3.2.5
- eslint-config-prettier 9.1.0
- eslint-plugin-prettier 5.1.3

**Problema**: ❌ No hay archivos `.eslintrc` o `.prettierrc`

**Recomendación**: Crear configuración base

## Frontend

**Herramientas**: ESLint integrado en react-scripts

**Ejecuta automáticamente** en `npm start`

## Quick wins

Crear `.eslintrc.json` y `.prettierrc` en backend  
Añadir script `lint` en package.json
